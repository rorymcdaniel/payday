# Support

Payday is community-maintained, pre-release software. Help is provided on a best-effort basis.

- Search existing issues before opening a new one.
- Use the bug report or feature request form for reproducible, non-sensitive topics.
- Include your macOS version, Swift version, Payday commit or version, and whether the issue occurs in Practice Mode.
- Use only synthetic category names, amounts, screenshots, and exported data.

Never post a YNAB token, budget ID, account ID, transaction ID, local database, history export, or real financial screenshot. Report security problems through the private process in [SECURITY.md](SECURITY.md).

Payday is not financial advice and is not affiliated with YNAB. Questions about YNAB accounts, transactions, reconciliation, or service availability belong with YNAB support.
